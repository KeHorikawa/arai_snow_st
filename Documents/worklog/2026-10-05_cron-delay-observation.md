## 2. 分かったこと

### 無人稼働そのものは問題ない

**8日連続で成功、抜けた日はゼロ。** 10月の観察の主目的（毎朝確実に動くか）については合格。

### 遅延が「安定しすぎている」

| | |
|---|---|
| 遅延の幅 | 309〜347分（**ぶれは38分**） |
| 実行時刻 | いつも 15:39〜16:17 JST に収まる |

混雑による遅れなら、曜日や日によってもっとばらつくはず。
8日間ずっと5時間半前後というのは、**混雑というより構造的な遅れ**に見える。

### 曜日の影響はあるが、小さい

| | 平均遅延 |
|---|---|
| 土日（3件） | 317分 |
| 平日（5件） | 335分 |

差は18分。負荷の影響は確かにあるが、**5時間超の本体部分は説明できない。**

## 3. 判断：分だけ `:30` → `:17` に変える

GitHub は「毎時0分などの混む時刻を避けて分を散らす」ことを推奨している。
`:30` も切りのいい時刻なので、混雑を踏んでいる可能性がある。試す価値はある。

**ただし時（hour）は動かさない。** 理由は、外れたときの損を出さないため。

| 設定 | 遅延が消えた場合 | 遅延が続いた場合 |
|---|---|---|
| 変更前 `30 1`（10:30 JST） | 10:30 | 15:40〜16:17 |
| **採用 `17 1`（10:17 JST）** | **10:17** | **15:27〜16:04**（ほぼ現状維持） |
| 検討 `17 2`（11:17 JST） | 11:17 | 16:27〜17:04（**現状より47分悪化**） |

`17 1` は、分を変える実験としては `17 2` と同じことをしていて、**外れたときの損だけが無い。**

### 採らなかった案

| 案 | 却下の理由 |
|---|---|
| `17 2`（11:17 JST） | 当たれば11:17だが、外れると17時台。実験の中身は `17 1` と同じで、損だけ増える |
| もっと早い時刻へ倒す（例 `47 19` = 翌4:47 JST） | 5時間半遅れても10時台に着地する。ただし**遅延が突然解消すると市の更新前に取りに行き、常に1日遅れのデータ**になる |
| 1日2回に増やす | 市サーバーへのリクエストが1日2ページ→4ページ。「毎朝は1ページだけ」という方針から外れる。分の変更が効かなかった場合の次善策として保留 |

## 4. 変更内容

`.github/workflows/collect.yml`

```diff
   schedule:
-    # 10:30 JST（UTC 01:30）。
-    - cron: "30 1 * * *"
+    # 10:17 JST（UTC 01:17）。分を :30 から :17 にずらしている。
+    - cron: "17 1 * * *"
```

変更の理由をコメントとしてワークフロー内にも残した（観測した遅延の実数を含む）。

あわせて README と `Documents/de-streamlit_notes.md` の構成図の時刻表記を更新。

**過去の作業ログ（9/22・9/26）の「10:30」はそのまま残す。** その時点の記録であり、書き換えない。

## 5. 次の確認

1週間ほど（2026-10-12 ごろまで）観測し、同じ方法で遅延を測り直す。

| 結果 | 次の手 |
|---|---|
| 遅延が数十分以内に収まる | 完了。必要なら時刻の微調整 |
| 変わらず5時間半前後 | 分の違いは無関係と判断。「早い時刻へ倒す」か「1日2回」を検討する |
| 日によって大きくばらつくようになる | 時刻を狙うこと自体を諦め、**遅延前提の設計**（表示側に観測日を出す）で割り切る |

**11月の降雪開始までに決着させる。** 冬に入ってから調整すると、実データで検証しにくくなる。

なお、この観測とは別に、**11月の降雪開始前に手動実行して生存確認する**運用は変わらず必要
（GitHub の60日ルールへの保険）。

## 6. 記事にする際の要点

- **「動いた」と「狙った時刻に動いた」は別**。8日連続成功という結果の裏で、毎日5時間半遅れていた
- 遅延のばらつきが38分しかないことから、混雑ではなく構造的な遅れだと推測できた。
  **ばらつきの大きさが、原因を絞る手がかりになる**
- **外れたときに損をしない変更を選ぶ**。`17 2` と `17 1` は実験としては同じで、後者だけが安全
- cron は「その時刻に動く」保証ではない。**無料枠の公開リポジトリでは特にそう**
