# 妙高市 降雪・積雪データ可視化アプリ

新潟県妙高市の雪情報ホームページから降雪量・積雪量データを取得し、グラフで可視化するStreamlitアプリケーションです。

## 概要

このアプリは、妙高市が公開している月別の降雪・積雪データを、視覚的に分かりやすいグラフで表示します。

データの取得はアプリとは切り離してあり、**GitHub Actions が毎朝1回まとめて取得**します。
アプリは保存されたデータを読むだけなので、表示のたびに市のサイトへ取りに行くことはありません。

### 主な機能

- **グラフ表示**: 降雪量（棒グラフ）と積雪量（折れ線グラフ）を同一グラフに表示
- **条件選択**: 年・月・観測地点を最大3件まで選択可能
- **毎朝の自動更新**: GitHub Actions が収集し、リポジトリにコミットする（[詳細](#データ収集の自動化github-actions)）

### 対象観測地点

1. 新井消防署
2. 頸南消防署
3. 妙高市役所 妙高支所

### 対象期間

平成21年度（2009年）から令和7年度（2026年3月）までの冬季データ
- 対象月: 11月、12月、1月、2月、3月、4月（過去に5月のページが1件あります）
- 市のサイトで公開されている月別ページ97件すべてを収録しています

```

```

## 使い方

### アプリの起動

```bash
streamlit run main.py
```

ブラウザが自動的に開き、アプリが表示されます。
通常は `http://localhost:8501` でアクセスできます。

### 操作方法

1. **サイドバーで条件を選択**
   - 年を選択
   - 月を選択（選択した年で利用可能な月のみ表示）
   - 観測地点を選択
   - 最大3件まで条件を設定可能

2. **グラフを確認**
   - 選択した条件に応じて、グラフが縦に並んで表示されます
   - 青色の棒グラフ: 降雪量（cm）
   - 赤色の折れ線グラフ: 積雪量（cm）

3. **デフォルト表示**
   - アプリ起動時は、最新データが存在する月の3地点分のグラフを自動表示

### データについて

- **観測時刻**: 9時
- **降雪量**: 前日からの降雪量
- **積雪量**: 観測日当日の積雪量
- **欠測値**: データがない日は「-」で表示され、グラフ上では非表示

## データ収集の自動化（GitHub Actions）

データの取得は、アプリの表示とは切り離して GitHub Actions が毎朝1回行います。
アプリ側は保存されたデータを読むだけで、市のサイトへは取りに行きません。

```
GitHub Actions（毎朝 10:17 JST）
  └ collect.py
       ├ snow_data_history.csv   全シーズンの観測データ（唯一の正）
       ├ docs/data/snow_data.json  最新シーズンの表示用データ（静的サイトが読む）
       └ data/status.json        実行記録
                  ↓ 変更があればコミット
main.py（Streamlit）… 保存されたデータを読んで描く
```

### collect.py の使い方

```bash
pip install -r requirements-collect.txt

python collect.py            # 当シーズンの最新月ページ1枚だけ取得（毎朝これが走る）
python collect.py --all      # 全期間をバックフィル（初回に1回だけ）
python collect.py --dry-run  # 取得して結果を表示するが、ファイルは書かない
```

市のサーバーに負担をかけないよう、**毎朝の実行で取りに行くのは一覧ページ1枚と当シーズンの該当月1枚だけ**です。
`--all` は初回のバックフィル専用で、1.5秒の間隔を空けて取得します。

### 手動で実行する

GitHub の Actions タブ → 「collect snow data」 → 「Run workflow」から、いつでも手動実行できます。

### ワークフローが失敗する条件

失敗するとGitHubからメールが届きます。届いたら、人が確認すべきことが起きています。

| 状況 | 扱い |
|---|---|
| 一覧ページが取得できない（通信エラー等） | 失敗 |
| 一覧ページから月別リンクが1件も見つからない | 失敗 |
| 当シーズンのページはあるのに、表や日付の行が取れない | 失敗 |
| 既存データと矛盾する（その月の日数が既存の8割未満） | 失敗 |
| **当シーズンのページがまだ公開されていない** | **成功**（オフシーズンの正常な状態） |
| 今日の行がまだ「-」（欠測） | 成功 |
| 変化がなく、コミットするものがない | 成功 |

新しいシーズンのページは例年11月に公開されますが、**暦の月では判定していません**。
過去17シーズンのうち11月のページがあるのは12シーズンだけで、
雪が降らなければ市が11月分を出さない年があるためです。
判定の基準は「新しいページが公開されたか」の一点だけです。

### 運用上の注意：スケジュール実行の自動停止

**GitHub は、公開リポジトリで60日間活動がないと、定時実行（cron）のワークフローを自動的に無効化します。**
無効化されてもエラーにはならず、静かに動かなくなります。

`data/status.json` を毎日更新することで毎日コミットが発生しますが、
**bot（`github-actions[bot]`）のコミットが「活動」とみなされるかは確認できていません。**
そのため、次の2点で運用を担保します。

1. **GitHubからの「停止予告メール」を見逃さないこと。**
   無効化の前に、リポジトリのオーナー宛に通知が届きます
2. **11月の降雪開始前に、必ず手動実行して生きていることを確認すること。**
   Actions タブから手動実行し、緑になることと `data/status.json` が更新されることを確かめます

### 既知の制約

- **月替わり直後に前月の数字が訂正されても反映されません。**
  毎朝取得するのは当シーズンの最新月1枚だけのため、たとえば12月に入ったあとで
  11月分の数字が訂正されても拾えません。必要なときは `python collect.py --all` を手動で実行してください
- **観測データに欠測（`-`）があります。** 「今朝の数値」が今日のものとは限りません。
  `docs/data/snow_data.json` の `latest.observed_date` に、実際の観測日が入っています

## トラブルシューティング

### データが表示されない

アプリは保存されたファイルを読むだけなので、インターネット接続は必要ありません。

- `snow_data_history.csv` が存在するか確認してください
- 「まだ収集されていません」と表示される場合は、その年月がまだ収集されていません。
  `python collect.py --all` を実行すると全期間を取得できます
- 「全日が欠測」と表示される場合は、市のページにその月の観測値が入っていません（データ側の状態です）
- データの更新が止まっている場合は、`data/status.json` と GitHub の Actions タブを確認してください

### エラーメッセージが表示される

- `data_urls.csv` ファイルが存在し、正しい形式であることを確認してください
- 必要なパッケージがすべてインストールされているか確認してください

```bash
pip install -r requirements.txt
```

### HTML構造の変更について

妙高市のウェブサイトのHTML構造が変更された場合、データ取得が失敗します。
この場合は**ワークフローが失敗してメールが届く**ので、気づかないまま古いデータを見続けることはありません。
修正が必要なのは `collect.py` の `parse_month_page()` 周辺です。

## 開発者向け情報

### データ構造

内部では以下の形式（tidyデータ）でデータを保持しています：

| year | month | day | location | snowfall_cm | snowdepth_cm |
|------|-------|-----|----------|-------------|--------------|
| 2024 | 12    | 1   | 新井消防署 | 10.0        | 50.0         |

### テスト

ブラウザを開かずに画面を検査するテストがあります（`streamlit.testing.v1.AppTest` を使用）。

```bash
python tests/test_app.py     # そのまま実行（pytest不要・約1秒）
pytest tests/test_app.py     # pytest があればこちらでも
```

`main.py` を変更したときは、これを走らせてから公開してください。

### キャッシュの削除

サイドバー下部の「🔄 データを再読み込み」ボタンで、キャッシュを一括クリアして保存ファイルを読み直します。

**このボタンは市のサイトへ取りに行くものではありません**（データ取得は GitHub Actions の担当です）。
`snow_data_history.csv` が更新されたのに画面が古いままのときに使います。
